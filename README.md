# HR_Analytics_Dashboard
# Project Overview
Interactive Power BI dashboard analyzing HR data of 500 employees 
to uncover insights on workforce composition, salary trends, 
performance, job satisfaction, and attrition patterns.

# Tech Stack
- MySQL (data storage)
- Power BI Desktop (dashboard & DAX)
- SQL (data analysis)

# Dashboard Pages
1. Workforce Analysis
2. Salary & Compensation
3. Performance & Job Satisfaction
4. Attrition & Resignation

# Key Insights
1. Total 500 employees, 455 active, 45 resigned, attrition rate 9%.
2. Engineering has the highest employees (117); Operations has the 
   highest resignations (10).
3. Average salary ₹79.54K; Engineering highest paying (₹153.15K max), 
   Customer Support lowest (₹31.58K).
4. Salary increases with tenure; Engineering shows strongest growth.
5. Performance ratings are healthy across departments.
6. Overtime employees show lower job satisfaction — burnout risk.
7. 7. Most resignations in early tenure; Operations department highest.
