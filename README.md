# HR_Analytics_Dashboard

HR Analytics Dashboard using MySQL and Power BI.

The project analysis employee workforce distribution,
compensation, performance, satisfaction, attrition,
and retention patterns.

# Tech Stack
Tool & Purpose 
| MySQL | Data storage & relational database |
| SQL | Data extraction, cleaning & analysis |
| Power BI Desktop| Interactive dashboard & visualization |
| DAX | KPIs & calculated measures |

# Dashboard Pages
1. Workforce Analysis — Employee distribution by department, role & location 
2. Salary & Compensation — Salary trends by department, role & tenure 
3. Performance & Job Satisfaction  — Performance Ratings & satisfaction analysis
4. Attrition & Resignation — Resignation patterns

# Key Insights
1. Total 500 employees, 455 active, 45 resigned, attrition rate 9%.
2. Engineering has the highest employees (117); Operations has the 
   highest resignations (10).
3. Average salary ₹79.54K; Engineering highest paying (₹153.15K max), 
   Customer Support lowest (₹31.58K).
4. Salary increases with tenure; Engineering shows strongest growth.
5. Performance ratings are healthy across departments.
6. Overtime employees show lower job satisfaction — burnout risk.
7. Most resignations in early tenure; Operations department highest.

8. ## 📈 KPIs Tracked

- Total Employees  
- Active vs. Resigned  
- Attrition Rate  
- Average Salary  
- Department-wise Performance  
- Job Satisfaction Score  
- Overtime Impact
